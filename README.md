# Excel 交集与差集

使用 Python 3.10 或更高版本：

```sh
python -m pip install -r requirements.txt
python test.py
```

1. 选择两个 `.xlsx` 或 `.xls` 文件，第一个为源表，第二个为目标表。也可以分两次各选择一个文件；重新选择一对文件会替换旧选择。
2. 点击“确定”，选择需要导出的列，以及至少一个共同筛选列。多个筛选列按组合键匹配，筛选列不必出现在输出列中。
3. 点击“求交集”或“求差集”，选择保存位置。结果使用 `.xlsx` 格式，不允许覆盖输入文件；覆盖其他已有文件时会要求确认。

交集只输出匹配记录，保留所有匹配组合；若同一个键在两表中分别出现两次和三次，会输出六个组合。双方同时输出的同名非键列分别加 `_源表`、`_目标表` 后缀。

差集输出源表中在目标表找不到匹配键的记录，只包含选择的源表列，并保留源表原有的重复记录和顺序。目标表输出列仅用于交集。空筛选值遵循 pandas 的合并规则：空值与空值匹配。

读取各工作簿的第一个工作表，以第一行作为表头。表头可以是文本、数字或日期。运行期间修改了文件结构时，请重新选择文件。原始文件的公式、样式及其他工作表不会复制到结果文件。

运行回归测试（GUI 测试使用无界面 Qt 平台）：

```sh
python -m unittest discover -s tests -v
```
